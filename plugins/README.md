# Plugins für den Paper Minecraft Server

In diesem Verzeichnis finden Sie die Plugins, die für den Paper Minecraft Server verwendet werden. Plugins erweitern die Funktionalität des Servers und bieten zusätzliche Features, die das Spielerlebnis verbessern.

## Installation von Plugins

Um ein Plugin zu installieren, folgen Sie diesen Schritten:

1. Laden Sie die Plugin-Datei (in der Regel eine `.jar`-Datei) herunter.
2. Kopieren Sie die `.jar`-Datei in das `plugins`-Verzeichnis des Paper Minecraft Servers.
3. Starten Sie den Server neu, damit das Plugin geladen wird.

## Konfiguration von Plugins

Viele Plugins bieten Konfigurationsdateien, die im `plugins`-Verzeichnis erstellt werden, nachdem das Plugin zum ersten Mal gestartet wurde. Um die Einstellungen eines Plugins anzupassen:

1. Öffnen Sie die entsprechende Konfigurationsdatei im `plugins`-Verzeichnis.
2. Nehmen Sie die gewünschten Änderungen vor.
3. Speichern Sie die Datei und starten Sie den Server neu, um die Änderungen zu übernehmen.
