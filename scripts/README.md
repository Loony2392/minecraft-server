# Übersicht über die Skripte

In diesem Verzeichnis befinden sich Skripte, die zur Verwaltung und Aktualisierung des Paper Minecraft Servers verwendet werden. 

## Skripte

- **update.sh**: Dieses Skript wird verwendet, um den Server und die installierten Plugins automatisch zu aktualisieren. Es führt die notwendigen Schritte durch, um sicherzustellen, dass die neuesten Versionen heruntergeladen und installiert werden.

## Verwendung

Um das Update-Skript auszuführen, navigieren Sie zum Verzeichnis `scripts` und führen Sie das Skript mit dem folgenden Befehl aus:

```bash
bash update.sh
```

Stellen Sie sicher, dass Sie über die erforderlichen Berechtigungen verfügen, um das Skript auszuführen.
